# browserlink
A browser you can set as default to direct you to other browsers

> [!important]
> Because Sparkle in versions 1.1.0-1.1.2 is unusable, you MUST update manually to 1.1.3 or above to make it functional. This is due to a permissions issue which is batched with these old versions.

# macOS versions support
The app supports version 14 (Sonoma) and newer.
The app is tested on macOS 27 beta, and is expected to work normally.

# Versions and support
## Supported versions
**Key**
| Symbol | Meaning |
| ----- | ----- |
| ✅ | Supported |
| 🟡 | Partial support |
| :x: | Not supported |

If a version is not technically and bug-supported, do not open an issue for it. Help will not be issued for these versions.
If a version is not security-supported, do not open a security report for it.

If a version is supported (bug or security), then open an issue (or security report) for the version. I will happily review and patch if it's supported.
**Prerelease versions** are always security and bug supported. However, they are not technically supported.

## Prerelease versions
> [!warning]
> Prerelease versions may contain serious bugs! Use with caution.

Prior to a stable version releasing, 1 or more prerelease versions may release beforehand.

The convention is usually that minor versions (x.x.1) will have 1-2 release candidates before release, and major versions (x.1) will have 1-2 betas, and 1-2 release candidates before the release.

You can opt in by choosing the relevant toggle in settings>update. This will automatically opt in the beta/rc updates. However, not all prerelease versions are on the Sparkle channel. You may have to download manually.
